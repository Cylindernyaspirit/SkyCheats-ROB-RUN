# SkyCheats for ROB RUN (free build)

Download: soon

Free build in the SkyCheats style: role-based aimbot, player ESP, camera and loot ESP, homestead cards.

## Aim

Role based: only enemy roles are targeted, police are skipped unless a filter is off. Bone priority head, smoothing 4.5, FOV 6, visibility on.

## Visual

Player ESP with role colors, camera ESP for security rooms, loot with tier colors, homestead cards for base raids.

## Install

Extract, admin loader, game, INSERT, load `heist`.

## Troubleshooting

Aim ignores police: correct default, disable the role filter for police fights. Cards missing: base module called only near homesteads.

Windows 10/11, Steam, EAC. Free.
